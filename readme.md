# Smart Student Performance Predictor 🚀

An advanced Machine Learning project that predicts student marks based on:
- Study Hours 📚
- Sleep Hours 😴
- Previous Marks 📊

## 🔧 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 📊 Features
- Multi-variable prediction
- Accuracy calculation
- Graph visualization
- User input system

## 🚀 How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run project:
   python main.py

## 📌 Example Input
Hours: 6  
Sleep: 8  
Previous: 60  

Output: Predicted Marks ≈ 72
