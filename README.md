 # 🎯 Smart Student Performance Predictor

This project is a Machine Learning-based system that predicts student marks based on study hours, sleep duration, and previous academic performance.

---

## 🧠 Project Overview

This project uses a **Linear Regression algorithm** to analyze how different factors affect student performance. It helps in understanding how study habits influence marks.

---

## ⚙️ Features

* 📊 Multi-variable prediction (Hours, Sleep, Previous Marks)
* 📈 Accuracy evaluation using R2 Score
* 📉 Graph visualization (Study Hours vs Marks)
* 🤖 Machine Learning model training
* 🧾 Simple and clean dataset handling

---

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

---

## 📊 Input Parameters

* Study Hours 📚
* Sleep Hours 😴
* Previous Marks 📈

---

## 🎯 Output

* Predicted Marks
* Model Accuracy Score

---

```bash
pip install -r requirements.txt

```
